# V0.7 Scope & Acceptance — Release Readiness

## 1. Phase goal

将 V0.6 已完成的平台从“功能完整的开发工程”推进到“可重复构建、可一键启动、可浏览器验收、可恢复、可交接”的 Release Candidate。

本阶段不增加教育业务功能，不等待 MODEL-3。

---

## 2. Required work

### WP-R1 Full-stack containerization

- 保留现有 infra compose；
- 增加包含 backend + frontend + MySQL + Redis + Neo4j 的完整启动方式；
- backend镜像构建可复现；
- frontend生产镜像可复现；
- model-service非核心依赖，若纳入只能optional/profile；
- 所有容器有合理healthcheck / dependency ordering；
- 从clean volumes启动成功。

### WP-R2 Release configuration hardening

- 完整 `.env.example`；
- release模式必须显式提供JWT/MySQL/Neo4j关键secret；
- 禁止真实secret入Git；
- CORS/API URL/issuer配置可外部化；
- production-like启动不得依赖Windows绝对路径；
- 日志不得输出token、password、password hash。

### WP-R3 Health / readiness / version

至少：

- `/actuator/health/liveness` 或等价；
- `/actuator/health/readiness` 或等价；
- version/build info；
- MySQL必要依赖状态；
- Neo4j状态；
- Redis按真实必要性标记critical/degraded；
- request ID/correlation ID贯穿API错误与日志。

### WP-R4 OpenAPI

生成可访问API规范，覆盖主要学生、教师、管理员/图谱API。

要求：

- JWT Bearer security scheme；
- 错误响应模型；
- 默认关闭或受控暴露管理信息；
- OpenAPI不能绕过现有授权。

### WP-R5 Synthetic Demo Seed

提供幂等或clean-rebuild demo seed。

最小fixture：

```text
1 system admin
2 teachers
2 courses
4+ students
teacher-course assignments
knowledge points
exercise units
questions
one valid Published Graph DAG
answers
RuleBeta mastery
recommendation snapshots
```

不得使用Junyi Research Student作为平台demo用户。

### WP-R6 Full-stack API smoke

clean stack上至少验证：

1. login；
2. student course read；
3. answer submit；
4. mastery/recommendation/path查询；
5. teacher assigned course analytics；
6. cross-course teacher 403；
7. graph query；
8. health/readiness。

### WP-R7 Browser E2E

优先 Playwright。

至少：

#### Student

- 登录；
- 进入课程；
- 打开Question并提交；
- 查看结果；
- 查看mastery；
- 查看recommendation；
- 查看learning path。

#### Teacher

- 登录；
- 只看到assigned course；
- 查看overview / KP analytics / heatmap；
- 下钻student；
- 对另一个course直接URL/API访问应403或UI安全失败。

#### Admin minimum

- 登录；
- 教师分配管理；
- 能看到GraphVersion/governance入口。

完整图发布可通过API smoke覆盖，不强求所有治理步骤都在浏览器点击，但底层必须是真实stack。

### WP-R8 Recovery drills

- backend restart；
- frontend restart；
- Neo4j restart；
- active graph query continuity/reprojection验证；
- MySQL failure -> readiness failure；
- Redis failure按真实语义验证；
- clean re-up无手工数据库修复。

### WP-R9 Backup/Restore

提供可运行脚本或Runbook：

- MySQL backup；
- restore到clean MySQL；
- schema history校验；
- 用户/课程/AnswerRecord/Mastery/GraphVersion关键计数；
- Neo4j由Published关系重建验证。

### WP-R10 CI Release Gate

新增或扩展CI：

- image build；
- full compose startup；
- readiness wait；
- synthetic seed；
- smoke；
- browser E2E（若runner允许）；
- cleanup。

不得删除现有backend/python/frontend/compose-config Gate。

## 3. Security regression

V0.6所有课程级授权必须继续成立。

至少自动验证：

```text
Teacher A -> Course A 200
Teacher A -> Course B 403
Student A -> Student B analytics 403/endpoint unavailable
Student -> teacher endpoint 403
Teacher -> course lifecycle / assignment management 403
TEACH_ADMIN/SYSTEM_ADMIN allowed
```

JWT过期/错误签名/无token必须有一致错误响应。

---

## 4. Reliability regression

必须保持：

- Answer clientRequestId idempotency；
- Mastery exactly-once；
- Graph failed projection keeps old active graph；
- Evidence re-resolution does not mutate Published graph；
- Recommendation snapshot version binding；
- UNKNOWN mastery semantics。

---

## 5. Performance evidence

受控环境记录：

- clean image build time；
- clean stack startup-to-ready；
- student answer HTTP P50/P95；
- mastery/recommendation/path HTTP P50/P95；
- teacher overview/KP/heatmap/student-detail HTTP P50/P95；
- basic concurrency smoke（例如10或20并发，具体值按执行环境固定）；
- backend memory/CPU snapshot。

只作为demo/工程证据，不声称生产SLA。

## 8. Final Gate

Only：

### GO_RELEASE_CANDIDATE

所有核心flow在clean full stack可重复通过，安全/恢复/文档满足DoD。

### CONDITIONAL_GO

核心功能可靠，但存在不影响求职demo的明确非阻塞限制；必须列出并有后续处理计划。

### NO_GO

clean启动、核心E2E、权限、数据恢复或关键可靠性存在阻塞问题。

Gate后STOP，不自动进入V1.0或模型集成。

# V1 产品重构迁移计划

## 总原则

不推翻V0.7工程底座，不重写算法实验，不把Junyi研究数据删除；通过新增业务内容和重构前端信息架构，将产品重新对齐《离散数学》教学优化平台。

## 阶段A：课程与内容基线

- 建立《离散数学》主课程；
- 建立章/节/知识集/知识点内容模型适配；
- 首批覆盖：数理逻辑、集合论与关系、图论、代数结构；
- 准备中文知识点、关系、教学资源和练习的受控种子数据；
- Junyi保留在Research Data Domain，不作为前台课程。

## 阶段B：前端壳与角色路由

- 拆分当前单文件App.vue；
- 引入真正的角色门户和模块化路由；
- 学生/教师/管理员独立导航；
- 全中文设计系统和术语映射；
- 保持现有API兼容，先不重构后端服务边界。

## 阶段C：四大模块页面

1. 知识图谱可视化；
2. 教学资源整合与管理；
3. 个性化学习推荐；
4. 多元化教学评估。

## 阶段D：管理端拆分

- 用户与组织；
- 课程与教学；
- 教学资源；
- 知识图谱；
- 数据与评价；
- 系统设置。

## 阶段E：视觉与演示

- 首页和门户重做；
- 图谱画布与学习路径视觉统一；
- 资源卡片、图表、进度、标签体系统一；
- 生成完整中文Demo数据；
- Playwright覆盖学生/教师/管理员完整中文路径；
- 输出最终截图、Demo视频和简历素材。

## 迁移风险控制

- 不修改历史MODEL-0A~3结果；
- 不让Junyi Research Student进入业务用户；
- 不改变MySQL authority / Neo4j projection原则；
- 不破坏GraphVersion生命周期；
- 不修改RuleBeta语义；
- 不新增复杂AI模型。

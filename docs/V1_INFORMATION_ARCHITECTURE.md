## 中文术语替换

| 研发术语 | 前台中文 |
| --- | --- |
| KnowledgePoint | 知识点 |
| ExerciseUnit | 练习单元 / 知识练习 |
| Question | 题目 |
| Mastery | 掌握度 |
| UNKNOWN | 暂无学习数据 |
| Recommendation | 学习推荐 |
| Learning Path | 学习路径 |
| GraphVersion | 图谱版本 |
| Evidence | 关系证据（仅高级治理） |
| Published Graph | 已发布知识图谱 |
| Teacher Analytics | 班级学情 |
| Student Detail | 学生学情详情 |

普通学生和教师界面不得直接出现内部ID、GraphVersion、Evidence、RuleBeta、REC_RULE_V1等技术名词。

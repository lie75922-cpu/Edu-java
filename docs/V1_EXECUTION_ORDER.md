# V1 执行顺序

1. 冻结现有后端行为与数据契约，不新增算法。
2. 建立离散数学课程内容种子与资源模型差距清单。
3. 拆分 App.vue，建立 Vue Router、角色布局、中文设计系统。
4. 学生端先完成：首页→课程→知识点→图谱→资源→推荐→路径→测验→学习报告。
5. 教师端完成：工作台→课程→资源→图谱备课→学情→评价。
6. 管理端完成：用户组织→课程教学→资源→图谱治理→数据评价→系统设置。
7. 补齐教学资源模型与API，只在现有后端无法支撑申报书功能时新增数据库结构。
8. 完成离散数学中文Demo数据，至少能完整演示图论与数理逻辑两条学习路径，并覆盖集合论/关系与代数结构的课程目录。
9. Playwright重写为中文角色流程。
10. 最终通过产品验收、工程回归和截图评审后再冻结。

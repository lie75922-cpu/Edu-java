# V1 中文教学平台视觉规范（首版）

## 目标气质

专业、清晰、可信、现代教育数字平台。避免开发者控制台、实验面板、数据表单堆叠感。

## 页面框架

- 顶部：平台名称、当前课程、消息/帮助、用户信息；
- 左侧：角色级模块导航；
- 主区：面包屑 + 页面标题 + 关键摘要 + 核心内容；
- 次级内容通过标签页/抽屉/详情页展开，不在单页堆积。

## 学生端

重点视觉组件：
- 今日学习卡片；
- 课程进度环/进度条；
- 薄弱知识卡；
- 个性化路径时间线/节点图；
- 知识图谱画布；
- 教学资源卡片；
- 错题与测验结果；
- 学习报告图表。

## 教师端

重点视觉组件：
- 班级概览指标；
- 知识点掌握分布；
- 学生学习进度分层；
- 高频错误/难点；
- 资源使用情况；
- 过程性/诊断性/结果性评价卡；
- 备课资源抽屉。

## 管理端

以后台管理系统形式组织，但必须模块化：
- 左侧一级模块；
- 列表页 + 搜索/筛选；
- 新建/编辑使用独立页面或抽屉；
- 高级图谱治理单独工作台；
- JSON只允许在高级导入/调试入口出现。

## 语言

- 普通用户界面100%自然中文；
- 不使用“Demo Algebra Foundations”“KnowledgePoint Analytics”“Student Detail”等英文标题；
- 不显示内部业务ID作为主要信息；
- UNKNOWN显示“暂无学习数据”；
- RuleBeta不作为学生可见名词；
- Evidence / GraphVersion只在高级治理中出现，并辅以中文解释。
